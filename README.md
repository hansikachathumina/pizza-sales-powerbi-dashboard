# 🍕 Pizza Sales Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **Pizza Sales Analysis Dashboard**
developed using **Microsoft Power BI**.

The dashboard analyzes pizza sales performance using KPIs, trends,
category analysis, size analysis, and best/worst-selling pizza analysis.

## 🎯 Project Objectives

-   Analyze overall pizza sales performance
-   Monitor revenue and order performance
-   Analyze daily and monthly order trends
-   Analyze sales by pizza category
-   Analyze sales by pizza size
-   Identify best-selling pizzas
-   Identify worst-performing pizzas
-   Present business insights using interactive visualizations

## 📌 Dashboard Pages

### 1. Sales Overview

The Sales Overview page contains:

-   Total Revenue
-   Average Order Value
-   Total Pizzas Sold
-   Total Orders
-   Average Pizzas per Order
-   Total Orders by Day
-   Monthly Trend for Total Orders
-   Sales by Pizza Category
-   Sales by Pizza Size
-   Total Pizzas Sold by Pizza Category

### 2. Best & Worst Sellers

#### Best Sellers

-   Top 5 Pizzas by Revenue
-   Top 5 Pizzas by Quantity
-   Top 5 Pizzas by Total Orders

#### Worst Sellers

-   Bottom 5 Pizzas by Revenue
-   Bottom 5 Pizzas by Quantity
-   Bottom 5 Pizzas by Total Orders
